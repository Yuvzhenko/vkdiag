Детальний опис

Реалізація-заглушка (Mock/Stub) сервісу пакетів для використання в юніт-тестах.

Цей клас дозволяє тестувати логіку VkDiag.Program.CheckAppxPackages без необхідності мати реальні встановлені пакети Windows Store або викликати системні API.
