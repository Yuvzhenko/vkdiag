Детальний опис

Статичний клас для низькорівневої взаємодії з Windows Package Manager API.

Цей клас використовує P/Invoke виклики (згенеровані CsWin32) для доступу до функцій appmodel.h та shlwapi.h. Він дозволяє отримувати інформацію про встановлені Appx/MSIX пакети, їх версії та локалізовані назви.

Увага: Клас використовує unsafe код для роботи з вказівниками та буферами пам'яті.

Опис методів компонент

◆ FindPackagesByPackageFamily()

List< string > PackageManager::FindPackagesByPackageFamily ( string packageFamily)
static

Знаходить повні імена пакетів (Package Full Names) для заданого сімейства пакетів.

Аргументи
packageFamilyІм'я сімейства пакетів (Package Family Name), наприклад Microsoft.D3DMappingLayers_8wekyb3d8bbwe.
Повертає
Список рядків, що містять повні імена знайдених пакетів. Повертає порожній список, якщо пакети не знайдено.
Обробка виняткових ситуацій
Win32ExceptionВикидається, якщо Win32 API повертає помилку (крім ERROR_INSUFFICIENT_BUFFER при першому виклику).

Метод викликає PInvoke.FindPackagesByPackageFamily двічі:

  1. Перший раз: щоб отримати кількість пакетів (count) та необхідний розмір буфера (bufferLength).
  2. Другий раз: щоб заповнити виділені буфери реальними даними.

◆ GetAppStoreName()

string PackageManager::GetAppStoreName ( string packageFullName,
string defaultName )
static

Отримує локалізовану назву додатка з його ресурсів (App Store Name).

Аргументи
packageFullNameПовне ім'я пакета.
defaultNameЗначення за замовчуванням, якщо ресурс не знайдено.
Повертає
Локалізована назва програми або defaultName .

Використовує функцію PInvoke.SHLoadIndirectString для завантаження рядка ресурсу за URI схемою: PackageFullName?ms-resource://ResourceName}.
У даному випадку жорстко закодовано ресурс ms-resource://Microsoft.D3DMappingLayers/Resources/AppStoreName, що є специфічним для пакетів сумісності OpenCL/OpenGL.

◆ GetPackageVersion()

string PackageManager::GetPackageVersion ( string packageFullName,
string defaultVersion )
static

Отримує версію встановленого пакета.

Аргументи
packageFullNameПовне ім'я пакета (Package Full Name).
defaultVersionЗначення, що повертається у разі помилки або неможливості отримати версію.
Повертає
Рядок у форматі " v{Major}.{Minor}.{Build}.{Revision}" або defaultVersion .

Метод використовує PInvoke.OpenPackageInfoByFullName та PInvoke.GetPackageInfo для отримання структури PACKAGE_INFO. Далі відбувається ручний розбір бінарного буфера для вилучення полів версії з PACKAGE_VERSION struct.
