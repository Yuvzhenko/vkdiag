Детальний опис

Представляє об'єкт шару (Layer) з JSON-маніфесту Vulkan.

Цей клас використовується для десеріалізації масиву layers або кореневого об'єкта layer у файлах конфігурації Vulkan (наприклад, VK_LAYER_KHRONOS_validation.json).

Властивості цього класу автоматично заповнюються з ключів JSON у форматі snake_case (наприклад, library_path -> LibraryPath).

Див. офіційну документацію: Layer Manifest File Format

.

◆ ApiVersion

Версія Vulkan API, яку підтримує цей шар.

Зазвичай рядок у форматі "1.x.y", який пізніше парситься у System.Version.

◆ Description

string VkLayer::Description { get

Короткий опис призначення шару для відображення користувачу.

◆ DisableEnvironment

Dictionary<string, string> VkLayer::DisableEnvironment { get

Словник змінних середовища, наявність яких вимкне цей шар.

Дозволяє користувачеві примусово вимкнути неявний шар, встановивши відповідну змінну.

◆ EnableEnvironment

Dictionary<string, string> VkLayer::EnableEnvironment { get

Словник змінних середовища, наявність яких увімкне цей шар.

Використовується для неявних (implicit) шарів. Якщо змінна середовища задана, шар активується автоматично.

◆ ImplementationVersion

string VkLayer::ImplementationVersion { get

Версія реалізації самого шару.

Це число або рядок, що вказує на версію білда шару (не плутати з версією API).

◆ LibraryPath

string VkLayer::LibraryPath { get

Шлях до бінарного файлу бібліотеки (.dll або .so), що реалізує шар.

Може бути повним абсолютним шляхом або відносним (відносно розташування JSON-файлу).

string VkLayer::Name { get

Унікальне ім'я шару (наприклад, "VK_LAYER_KHRONOS_validation").

Рядок, що ідентифікує шар.

◆ Type

string VkLayer::Type { get

Тип шару.

Зазвичай приймає значення "INSTANCE", "DEVICE" або "GLOBAL". Сучасні шари переважно є "INSTANCE".
