Детальний опис

Політика іменування JSON-властивостей для конвертації у "snake_case".

Використовується при серіалізації/десеріалізації для сумісності зі стандартами Vulkan JSON-маніфестів, де ключі зазвичай записуються як layer_path або api_version, а не LayerPath.

Опис методів компонент

◆ ConvertName()

override string SnakeCasePolicy::ConvertName ( string name)

Конвертує вказане ім'я властивості у формат snake_case.

Аргументи
nameОригінальне ім'я властивості (зазвичай у PascalCase).
Повертає
Ім'я властивості у нижньому регістрі з підкресленнями між словами.
Приклад: ApiVersion -> api_version.

Алгоритм проходить по кожному символу:

  • Якщо символ у нижньому регістрі — додає його без змін.
  • Якщо символ у верхньому регістрі:
    • Якщо це початок слова (i > 0) — додає підкреслення _ перед символом.
    • Конвертує символ у нижній регістр.
