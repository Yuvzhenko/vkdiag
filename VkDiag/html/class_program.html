◆ CheckAppxPackages()

void Program::CheckAppxPackages ( IPackageService packageService)
staticprivate

Перевіряє наявність встановлених Appx-пакетів (MSIX), які відомі своєю несумісністю з Vulkan.

Метод перебирає список Constants.KnownPackages. Якщо знайдено проблемний пакет:

  1. Встановлюється глобальний прапорець everythingIsFine у false.
  2. У лог виводиться попередження з назвою та версією пакета.

Будь-які виключення під час пошуку пакетів ігноруються (try-catch без обробки), щоб не переривати роботу утиліти через помилки доступу до Windows Store API.

Аргументи
packageServiceІнтерфейс сервісу для отримання інформації про пакети (зазвичай WindowsPackageService).

◆ CheckVulkanMeta()

void Program::CheckVulkanMeta ( )
staticprivate

Виконує комплексну перевірку метаданих Vulkan (реєстрація драйверів та шарів) у системному реєстрі.

Метод складається з двох основних частин:

  1. Перевірка драйверів: Сканує ключі Drivers.
    • Видаляє записи, що вказують на неіснуючі файли JSON (якщо увімкнено autofix).
    • Якщо увімкнено clear, видаляє навіть валідні записи (legacy explicit registration), оскільки сучасні драйвери повинні реєструватися через Plug-n-Play (перевіряється в CheckGpuDrivers).
  2. Перевірка шарів (Layers): Сканує ключі ImplicitLayers та ExplicitLayers.
    • Виявляє та видаляє "мертві" посилання на файли.
    • Порівнює версії шарів з Constants.KnownProblematicLayers та пропонує вимкнути застарілі.
    • Виявляє дублікати шарів (однакові JSON, різні шляхи) та автоматично вимикає старіші версії, залишаючи лише найновішу.

◆ hasInactive

bool Program::hasInactive
staticprivate

Виконує глибоку діагностику встановлених графічних драйверів та їх реєстрації Vulkan.

Метод сканує системний реєстр за шляхом SYSTEM\CurrentControlSet\Control\Video.

Основні етапи роботи:

  1. Виявлення GPU: Розділяє знайдені пристрої на активні фізичні GPU та віртуальні/базові адаптери (фільтруючи їх через Constants.ServiceBlockList).
  2. Перевірка Vulkan: Шукає ключі VulkanDriverName та шари. Перевіряє фізичне існування зазначених JSON-файлів або DLL.
  3. Автовиправлення: Якщо увімкнено autofix, видаляє з реєстру записи, що вказують на неіснуючі файли.
  4. Перевірка актуальності: Аналізує дату драйвера. Виводить попередження, якщо драйвер старіший за 2 місяці, і помилку, якщо старіший за 6 місяців.
Повертає
Кортеж (ValueTuple<T1, T2>), що містить:
  • hasInactive: true, якщо знайдено віртуальні або неактивні адаптери (потрібно для перевірки налаштувань продуктивності).
  • hasVulkan: true, якщо знайдено хоча б один GPU з коректно зареєстрованим драйвером Vulkan.
