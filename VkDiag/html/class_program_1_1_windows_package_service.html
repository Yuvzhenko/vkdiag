Детальний опис

Реалізація сервісу пакетів для середовища Windows.

Цей клас виступає обгорткою над статичним класом VkDiag.Interop.PackageManager, забезпечуючи можливість підміни (mocking) у тестах через інтерфейс IPackageService.
