Детальний опис

Кореневий об'єкт (Root DTO) для десеріалізації JSON-маніфесту шару Vulkan.

Цей клас відображає структуру файлу маніфесту (наприклад, VkLayer_*.json). Властивості автоматично мапляться зі snake_case ключів JSON завдяки VkDiag.SnakeCasePolicy.

Див. специфікацію: Layer Manifest File Format

.

Компонентні дані

◆ FileFormatVersion

string VkRegInfo::FileFormatVersion { get

Версія формату файлу маніфесту (наприклад, "1.0.0", "1.1.2" або "1.2.0").

Відповідає ключу JSON file_format_version. Це поле визначає обов'язкові поля та структуру документа.

◆ Layer

VkLayer VkRegInfo::Layer { get

Об'єкт шару, визначений у маніфесті.

Відповідає ключу JSON layer. Це стандартний спосіб опису шару в сучасних маніфестах (починаючи з версії формату 1.1.0).

◆ Layers

List<VkLayer> VkRegInfo::Layers { get

Список шарів, визначених у маніфесті (для форматів, що підтримують множинні шари).

Відповідає ключу JSON layers. Хоча сучасна специфікація надає перевагу одиничному об'єкту layer, програма підтримує і старий формат зі списком для сумісності.
