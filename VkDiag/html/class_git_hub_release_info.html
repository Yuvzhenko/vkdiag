Детальний опис

Модель даних, що представляє інформацію про реліз на GitHub.

Використовується для десеріалізації JSON-відповіді від GitHub API. Властивості цього класу автоматично мапляться на snake_case ключі JSON (наприклад, TagName -> tag_name) завдяки політиці VkDiag.SnakeCasePolicy.
