string defaultTitle )

Отримує читабельну назву додатка (App Name) для відображення користувачеві.

Аргументи
fullNameПовне ім'я пакета (Package Full Name).
defaultTitleНазва за замовчуванням, яка буде повернута, якщо не вдасться отримати справжню назву з маніфесту пакета.
Повертає
Локалізована назва додатка або defaultTitle у разі помилки.

◆ GetVersion()

string GetVersion ( string fullName)

Отримує версію пакета на основі його повного імені.

Аргументи
fullNameПовне ім'я пакета (Package Full Name).
Повертає
Рядок з версією пакета (наприклад, "1.0.0.0"). Якщо версію не вдалося визначити, повертає порожній рядок.
